# Automatic Street Light System using LDR

A smart light management system that automatically turns LEDs ON in the dark and OFF in daylight using a Light Dependent Resistor (LDR) sensor.

## ⚙️ Working Principle

This project operates based on ambient light intensity:

* **Daylight Condition:** High light exposure increases the LDR's resistance, keeping the LEDs turned **OFF**.
* **Nighttime Condition:** Low light exposure drops the LDR's resistance, triggering the circuit to turn the LEDs **ON**.

*(Note: The LEDs represent street light prototypes in this circuit setup.)*

---

## 🛠️ Components Required

* Arduino / Breadboard
* LDR (Light Dependent Resistor)
* Resistors (10kΩ & 220Ω)
* LEDs
* Connecting Wires
